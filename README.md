# Relay: Accessible Messaging

Relay is a messaging app built for accessibility first. It works on phones, tablets and Android TV.

[**Get it on Google Play**](https://play.google.com/store/apps/details?id=online.relaaay)

Made by [Concise Design](https://concise.design). The source code is private; this repo is the app's public page and the place to report issues.
